# Contributing to HA-Phone

First of all, thank you for your interest in contributing to HA-Phone!

We welcome bug reports, feature requests, documentation improvements and code contributions.

## Before you start

- Please check existing Issues before creating a new one.
- If you plan a larger feature, open an Issue first to discuss the implementation.
- Keep Pull Requests focused on a single change whenever possible.

## Coding Guidelines

- Follow the existing coding style.
- Write clear and maintainable code.
- Update documentation when required.
- Test your changes before submitting.

## Pull Requests

When submitting a Pull Request, please:

- Describe what has changed.
- Explain why the change is necessary.
- Reference related Issues when applicable.
