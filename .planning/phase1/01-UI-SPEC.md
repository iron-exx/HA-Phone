## Phase 1 UI Scope Clarification

### What IS UI in Phase 1:

1. **Home Assistant Entities** (HA-01)
   - `sensor.alfen_eve_tag_socket_1` (RFID tag)
   - `sensor.alfen_energy_total` (energy meter)
   - Charging status sensor
   - **UI Contract:** These appear automatically in HA's entity list and dashboard when the Alfen integration is configured. No custom UI work needed.

2. **Dolibarr Module Activation** (DB-03, SEC-04)
   - Module appears in Dolibarr's module list (`htdocs/admin/modules.php`)
   - Admin clicks "Activate" to enable
   - SQL tables created automatically on activation
   - Permissions set up for Wallbox module
   - **UI Contract:** Uses native Dolibarr module administration interface. No custom UI work needed.

### What is NOT in Phase 1:

- ❌ No custom Dolibarr pages/tabs
- ❌ No user management UI (Phase 2)
- ❌ No billing dashboards (Phase 4)
- ❌ No RFID management UI (v2: UI-01)
- ❌ No real-time dashboards (v2: UI-02)

### Success Criteria Verification (UI Perspective):

| Criterion | UI Element | Status |
|-----------|------------|--------|
| HA shows Alfen sensors in entity list | Native HA entity list | ✅ Platform native |
| Dolibarr admin activates module | Native Dolibarr module list | ✅ Platform native |
| Module creates DB tables + permissions | Backend only (no UI) | ✅ No UI needed |
| Sensor updates in real-time in HA dashboard | Native HA dashboard | ✅ Platform native |
