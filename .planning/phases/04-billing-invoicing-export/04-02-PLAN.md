### generateCsv() (EXT-02)
CSV-Export für externe Analyse:

1. CSV mit fputcsv() erstellen (Semikolon-Trennzeichen)
2. Header-Zeile:
   ```csv
   user_id;user_login;name;billing_month;billing_year;total_kwh;price_per_kwh;total_cost;session_count
   ```
3. Eine Zeile pro User mit Abrechnungsdaten
4. UTF-8 Encoding mit BOM für Excel-Kompatibilität

### generateDatev() (EXT-03)
DATEV EXTF Format für deutsche Buchhaltung:

1. Kopfzeile: `EXTF YYYYMMDD;5` (Version 5)
2. Feld-Titel:
   ```csv
   Kennung;Vers;Konto;Gegenkonto (ohne);Belegdatum;Buchungstext;Soll/Haben;Betrag;KOST1;KOST2
   ```
3. Buchungssätze (pro User 2 Zeilen):
   - Zeile 1: Soll an Debitorenkonto
   - Zeile 2: Haben an Umsatzkonto (1400)
4. Betrag in Cent (kein Komma, kein Punkt)

### DATEV Konfiguration (aus RESEARCH.md)
```php
$config = array(
    'berater_nr' => '12345',      // Beraternummer
    'mandanten_nr' => '001',     // Mandantennummer
    'buchungskreis' => '00',    // Standard Buchungskreis
    'skonto' => '03'          // Kontenplan (SKR03)
);
```

### Hilfsmethoden
- `formatAmount()`: Betrag in Cent umrechnen
- `getDatevAccount()`: 5-stelliges Konto generieren (10000 + user_id)
- `formatDate()`: TT.MM.JJJJ Format
