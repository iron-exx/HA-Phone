### runMonthlyBilling() Methode (BIL-01)
Eingabe:
- `$user` (User-Objekt), `$month` (1-12, 0=Vormonat), `$year` (0=current)

Logik:
1. Zeitraum berechnen: vom 1. des Monats bis zum letzten Tag
2. Sessions abfragen aus `llx_wallbox_sessions`:
   ```sql
   SELECT s.fk_user, s.rfid_hash, u.login, u.lastname, u.firstname,
          SUM(s.kwh) as total_kwh,
          s.price_per_kwh,
          SUM(s.total_cost) as total_cost,
          COUNT(*) as session_count
   FROM llx_wallbox_sessions s
   LEFT JOIN llx_user u ON s.fk_user = u.rowid
   WHERE s.start_time >= '{start}'
     AND s.end_time <= '{end}'
     AND s.status = 'completed'
   GROUP BY s.fk_user, s.price_per_kwh
   ORDER BY u.login, s.start_time
   ```
3. Kosten berechnen: `total_cost = total_kwh * price_per_kwh` (BIL-03)
4. Billing History speichern in `llx_wallbox_billing_history`
5. `BillingHistory` Objekt mit Abrechnungsdaten zurückgeben

### createBillingHistory() Hilfsmethode
- Neuen Eintrag in `llx_wallbox_billing_history` erstellen
- Billing für jeden User mit allen Sessions speichern
- JSON-Codierte Session-Liste und Summary speichern

### Hilfsmethoden
- `getMonthDateRange($month, $year)`: Array mit start, end Returns
- `formatDate($timestamp)`: Deutsches Datumsformat
- `escape($str)`: SQL-Escape mit $db->escape()

### Deutsche Bezeichnungen (Sprache: Deutsch)

- Methoden: runMonthlyBilling, createBillingHistory, getMonthDateRange
- Variablen: $user, $month, $year, $month, $startDate, $endDate

### Cron-Job Array hinzufügen
Erweitern oder hinzufügen (nach `$this->rights`):

```php
$this->cronjobs = array(
    0 => array(
        'entity' => 0,
        'label' => 'Wallbox Monthly Billing',
        'jobtype' => 'method',
        'class' => 'wallboxbilling/class/billing.class.php',
        'objectname' => 'WallboxBilling',
        'method' => 'runMonthlyBilling',
        'parameters' => '',
        'comment' => 'Monatliche Wallbox-Abrechnung ausführen',
        'frequency' => 1,
        'unitfrequency' => 3600 * 24 * 30,  // ~30 Tage (Monat)
        'priority' => 50,
        'status' => 1,  // Aktiviert
        'test' => '$conf->wallboxbilling->enabled'
    )
);
```

## Implementierung: billing_history Tabelle

### SQL Migration erstellen
Neue Datei: `htdocs/custom/wallboxbilling/sql/migration_billing.sql`

```sql
-- Table for billing history
-- Stores completed monthly billing runs
CREATE TABLE IF NOT EXISTS llx_wallbox_billing_history (
    rowid INTEGER NOT NULL AUTO_INCREMENT PRIMARY KEY,
    fk_user INTEGER NOT NULL,
    billing_month INTEGER NOT NULL,
    billing_year INTEGER NOT NULL,
    total_kwh DECIMAL(10,2) NOT NULL DEFAULT 0,
    price_per_kwh DECIMAL(10,4) NOT NULL,
    total_cost DECIMAL(10,2) NOT NULL DEFAULT 0,
    session_count INTEGER NOT NULL DEFAULT 0,
    session_details LONGTEXT,  -- JSON encoded session list
    fk_user_creator INTEGER NOT NULL,
    date_creation DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    status INTEGER NOT NULL DEFAULT 1,
    UNIQUE KEY uk_user_month_year (fk_user, billing_month, billing_year)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### Hinweis
- `session_details` speichert JSON der individuellen Sessions
- `status` für zukünftige Erweiterungen (draft, created, paid)
- UNIQUE KEY verhindert Doppelabrechnung pro Monat/User
