**Key implementation rules:**
- Action handlers MUST be before `llxHeader()` (HTML output) — POST redirect with `header()` + `exit` only works before output
- `GETPOST('tab', 'aZ09')` — 'aZ09' filter allows alphanumeric only (tab parameter injection prevention, RESEARCH.md Security)
- `GETPOST('session_id', 'int')` — integer filter (RESEARCH.md Security)
- ALL DB text output MUST use `htmlspecialchars($value, ENT_QUOTES, 'UTF-8')` — especially `upload_error` (XSS, RESEARCH.md Security)
- cURL timeout: BOTH `CURLOPT_TIMEOUT` and `CURLOPT_CONNECTTIMEOUT` set to 4 (Pitfall 3)
- LEFT JOIN (not INNER JOIN) for both wallbox_rfid and user tables (Pitfall 6)
- `WALLBOXBILLING_HA_URL` read via `getDolGlobalString()` — never hardcoded (Anti-pattern)
- `dol_fiche_end()` MUST appear after all tab content before `llxFooter()` (Pitfall 2)
- `newToken()` in every POST form (CSRF, SEC-05)
- No `rfid_hash` column printed directly in HTML (SEC-01, SEC-02)
