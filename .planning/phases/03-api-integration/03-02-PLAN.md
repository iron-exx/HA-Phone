<action>
Erstelle `Dolibarr/wallboxbilling/class/api_wallboxbilling.class.php`:

1. **Klasse `WallboxbillingApi` extending `DolibarrApi`:**
   ```php
   require_once DOL_DOCUMENT_ROOT.'/api/class/api.class.php';
   
   class WallboxbillingApi extends DolibarrApi {
       /**
        * @var array $FIELDS_MANDATORY
        * Pflichtfelder für Session-Upload
        */
       public static $FIELDS_MANDATORY = array('rfid_hash', 'wallbox_id', 'start_time', 'end_time', 'kwh');
       
       /**
        * @var DoliDB $db Database handler
        */
       public $db;
   ```

2. **Methode `postSession($request_data = null)`:**
   - **Token-Validierung (SEC-03):** Parent-Klasse `DolibarrApi` prüft bereits DOLAPIKEY via `checkAuthentication()` (in `__construct` oder jeder API-Methode)
   - **Pflichtfelder prüfen:**
     ```php
     $this->_checkMandatoryParameters($request_data, self::$FIELDS_MANDATORY);
     ```
   
   - **Feld-Validierung:**
     - `rfid_hash`: 64-stelliger Hex-String (SHA-256), Regex: `/^[a-f0-9]{64}$/i`
     - `wallbox_id`: String, max 50 Zeichen
     - `start_time`, `end_time`: Gültiges Datumsformat (DateTime::createFromFormat)
     - `kwh`: Numerisch, >= 0, max 3 Nachkommastellen
   
   - **Duplikatsprüfung (verhindert double-charge):**
     ```php
     $sql = "SELECT rowid FROM ".MAIN_DB_PREFIX."wallbox_sessions 
             WHERE rfid_hash = '".$this->db->escape($rfid_hash)."' 
             AND start_time = '".$this->db->idate($start_time)."' 
             AND end_time = '".$this->db->idate($end_time)."'";
     $resql = $this->db->query($sql);
     if ($resql && $this->db->num_rows($resql) > 0) {
         return array('success' => false, 'message' => 'Session already exists');
     }
     ```
   
   - **User-ID auflösen (RFID → fk_user):**
     ```php
     $sql = "SELECT fk_user FROM ".MAIN_DB_PREFIX."wallbox_rfid 
             WHERE rfid_hash = '".$this->db->escape($rfid_hash)."'";
     $resql = $this->db->query($sql);
     $fk_user = 0; // Default: unbekannt
     if ($resql && ($obj = $this->db->fetch_object($resql))) {
         $fk_user = $obj->fk_user;
     }
     ```
   
   - **Session speichern:**
     ```php
     $now = $this->db->idate(dol_now());
     $sql = "INSERT INTO ".MAIN_DB_PREFIX."wallbox_sessions 
             (fk_user, rfid_hash, wallbox_id, start_time, end_time, kwh, price_per_kwh, total_cost, created_at, transmitted_at)
             VALUES (".$fk_user.", 
             '".$this->db->escape($rfid_hash)."',
             '".$this->db->escape($wallbox_id)."',
             '".$this->db->idate($start_time)."',
             '".$this->db->idate($end_time)."',
             ".(float)$kwh.",
             0.0, 0.0, '".$now."', '".$now."')"; // transmitted_at = now (from API)
     $resql = $this->db->query($sql);
     if (!$resql) {
         return array('success' => false, 'message' => 'DB Error: '.$this->db->lasterror());
     }
     $session_id = $this->db->last_insert_id(MAIN_DB_PREFIX.'wallbox_sessions');
     return array('success' => true, 'id' => $session_id, 'message' => 'Session stored');
     ```

3. **SQL-Injection Prävention (SEC-05):** $this->db->escape() für alle Strings, type-casting für numerische Werte

4. **Error Responses:**
   - 400 Bad Request: Fehlende Pflichtfelder, ungültige Formate
   - 401 Unauthorized: Token ungültig (DolibarrApi handled)
   - 500 Internal Server Error: DB-Fehler
</action>

<acceptance_criteria>
- `Dolibarr/wallboxbilling/class/api_wallboxbilling.class.php` existiert
