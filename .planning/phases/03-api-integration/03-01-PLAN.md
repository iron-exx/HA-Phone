# Plan 03-01: HA Addon API Client

## Objective
HA-Addon sendet abgeschlossene Sessions via REST API an Dolibarr (JSON-Payload mit RFID-Hash, Wallbox-ID, Start/End-Zeit, kWh). API-Authentifizierung mit DOLAPIKEY Token. Retry-Mechanismus mit exponential backoff bei Fehlern.

Erstelle `Homeassistant/api_client.py` mit folgenden Komponenten:

1. **Klasse `WallboxApiClient`:**
   - `__init__(self, base_url: str, api_token: str, timeout: int = 30)`
   - Attribute: `self.base_url`, `self.headers = {"DOLAPIKEY": api_token, "Content-Type": "application/json"}`, `self.timeout`

2. **Retry-Konfiguration (D-02: Konservativ):**
   ```python
   from requests.adapters import HTTPAdapter
   from urllib3.util.retry import Retry
   
   retry_strategy = Retry(
       total=5,
       backoff_factor=0.5,  # 1s initial (0.5 * 2^0 = 0.5, aber min 1s)
       status_forcelist=[429, 500, 502, 503, 504],
       allowed_methods=["POST"],
       raise_on_status=False
   )
   adapter = HTTPAdapter(max_retries=retry_strategy)
   self.session = requests.Session()
   self.session.mount("https://", adapter)
   self.session.mount("http://", adapter)
   ```

3. **Methode `transmit_session(self, session_data: dict) -> tuple[bool, str]`:**
   - URL: `f"{self.base_url}/custom/wallboxbilling/api/session.php"`
   - Payload (D-04): 
     ```python
     payload = {
         "rfid_hash": session_data["rfid_hash"],
         "wallbox_id": session_data["wallbox_id"],
         "start_time": session_data["start_time"],  # ISO 8601
         "end_time": session_data["end_time"],        # ISO 8601
         "kwh": round(session_data["kwh"], 3)
     }
     ```
   - RFID immer als SHA-256 Hash (API-05, SEC-03)
   - `response.raise_for_status()` für HTTP 4xx/5xx
   - Return: `(True, "")` bei Erfolg, `(False, error_msg)` bei Fehler

4. **Methode `check_connection(self) -> bool`:**
   - GET auf `f"{self.base_url}/api/index.php/login"` (Dolibarr Login-Endpoint prüfen)
   - Return: True wenn status_code == 200

5. **Zeitstempel-Formatierung:**
   - Hilfsfunktion `format_timestamp(dt) -> str` für ISO 8601: `"%Y-%m-%dT%H:%M:%S%z"` (z.B. "2026-05-05T14:30:00+02:00")
</action>
